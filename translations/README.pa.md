# dpdp-law-to-code

**ਭਾਰਤ ਦਾ ਡਿਜੀਟਲ ਨਿੱਜੀ ਡਾਟਾ ਸੁਰੱਖਿਆ ਐਕਟ, 2023 — ਚਲਾਉਣ ਯੋਗ Python ਕੋਡ ਵਜੋਂ। MIT · ₹0 · ਸਥਾਨਕ-ਪਹਿਲਾਂ।**

ਭਾਰਤ ਸਰਕਾਰ ਨੇ ਜਿਸ ਢਾਂਚੇ ਦੀ ਜਨਤਕ ਖੋਜ ਸ਼ੁਰੂ ਕੀਤੀ ਹੈ, ਇਹ ਉਸ ਦਾ ਇੱਕ ਨਾਗਰਿਕ-ਨਿਰਮਿਤ ਹਵਾਲਾ ਲਾਗੂਕਰਨ।

## ਇਹ ਕਿਉਂ ਹੈ — MeitY ਦਾ ਸੰਕੇਤ

20 ਮਈ 2026 ਨੂੰ *Economic Times* ਨੇ ਖ਼ਬਰ ਦਿੱਤੀ ਕਿ **ਇਲੈਕਟ੍ਰਾਨਿਕਸ ਅਤੇ ਸੂਚਨਾ ਤਕਨਾਲੋਜੀ ਮੰਤਰਾਲਾ (Ministry of Electronics and IT — MeitY)** **"Law-to-Code"** ਨਾਮ ਦੇ ਇੱਕ ਸੰਕਲਪ — DPDP Act 2023 ਦੀਆਂ ਵਿਵਸਥਾਵਾਂ ਨੂੰ ਮਸ਼ੀਨ-ਚਲਾਉਣਯੋਗ ਐਲਗੋਰਿਦਮ ਵਿੱਚ ਅਨੁਵਾਦ ਕਰਨ — ਉੱਤੇ ਉਦਯੋਗਿਕ ਹਿੱਸੇਦਾਰਾਂ ਨਾਲ ਵਿਆਪਕ ਸਲਾਹ-ਮਸ਼ਵਰਾ ਕਰ ਰਿਹਾ ਹੈ।

ਹਿਮਾਂਸ਼ੀ ਲੋਹਚਬ ਅਤੇ ਸੁਭਾਯਨ ਚਕਰਵਰਤੀ ਦਾ ਲੇਖ *"Coded Compliance: Centre is Eyeing 'Law-to-code' to AI-proof Data Law"* (Economic Times, 20 ਮਈ 2026) ਅਨੁਸਾਰ, ਇਹ ਸਲਾਹ-ਮਸ਼ਵਰੇ ਲਗਭਗ ਇੱਕ ਮਹੀਨੇ ਤੋਂ ਚੱਲ ਰਹੇ ਹਨ ਅਤੇ ਫ੍ਰੰਟੀਅਰ AI ਮਾਡਲਾਂ ਦੀ ਤੇਜ਼ ਤਰੱਕੀ ਪ੍ਰਤੀ MeitY ਦੇ ਵਿਆਪਕ ਜਵਾਬ ਦਾ ਹਿੱਸਾ ਹਨ।

> *"Law-to-code is the practice of translating legal rules into machine-executable algorithms such as a Python code that software can automatically process and enforce without human intervention."*

> *"A 'base code' for legal provisions can ensure that systems are compliant by design without needing an army of lawyers to interpret every technical step."*

**ਇਹ ਰਿਪੋਜ਼ਟਰੀ ਸਰਕਾਰ ਵੱਲੋਂ ਜਨਤਾ ਅੱਗੇ ਰੱਖੇ ਸਵਾਲ ਦਾ ਇੱਕ ਨਾਗਰਿਕ ਦਾ ਜਵਾਬ ਹੈ।** ਇਹ ਮੁਕਾਬਲੇ ਵਾਲਾ ਪ੍ਰਸਤਾਵ ਨਹੀਂ ਹੈ, ਆਲੋਚਨਾ ਵੀ ਨਹੀਂ — ਇੱਕ ਕੰਮ ਕਰਨ ਵਾਲਾ, ਓਪਨ-ਸੋਰਸ ਹਵਾਲਾ ਲਾਗੂਕਰਨ। ਜੇ MeitY ਰਸਮੀ ਢਾਂਚਾ ਪ੍ਰਕਾਸ਼ਿਤ ਕਰਦਾ ਹੈ, ਇਹ ਰਿਪੋਜ਼ਟਰੀ ਉਸ ਅਨੁਸਾਰ ਅੱਪਡੇਟ ਕੀਤੀ ਜਾਵੇਗੀ।

## ਇਹ ਕੀ ਹੈ

DPDP Act 2023 (ਧਾਰਾਵਾਂ 5–16) — `pip install` ਕਰਨ ਯੋਗ Python ਲਾਇਬ੍ਰੇਰੀ। ਹਰ check `ComplianceResult` ਵਾਪਸ ਕਰਦਾ ਹੈ, ਕਾਨੂੰਨੀ ਹਵਾਲੇ ਨਾਲ।

## ਕਿਵੇਂ ਵਰਤਣਾ ਹੈ — ਤਿੰਨ ਰਾਹ

### ਰਾਹ A — ਆਪਣੇ Python codebase ਵਿੱਚ (ਡਿਵੈਲਪਰ)
`from dpdp.consent import check_consent` — request handler ਜਾਂ CI pipeline ਵਿੱਚ।

### ਰਾਹ B — ਟਰਮੀਨਲ ਤੋਂ (ਪਾਲਣਾ ਅਫ਼ਸਰ)
```bash
dpdp-check --section 6 --input consent.json
```

### ਰਾਹ C — AI ਸਹਾਇਕ ਰਾਹੀਂ (ਵਕੀਲ, ਸੰਸਥਾਪਕ)

Claude / Cursor / ChatGPT / Gemini ਨੂੰ ਕਹੋ — ਉਹ ਖੁਦ ਲਾਇਬ੍ਰੇਰੀ install ਕਰਕੇ check ਕਰੇਗਾ।

**⚠ ਜ਼ਰੂਰੀ ਡਾਟਾ-ਸੰਭਾਲ ਨੋਟਿਸ:**

DPDP Act 2023, **ਧਾਰਾ 8(5)** ਅਨੁਸਾਰ ਹਰ Data Fiduciary "ਵਾਜਬ ਸੁਰੱਖਿਆ ਉਪਾਅ" ਅਪਣਾਉਣਾ ਜ਼ਰੂਰੀ ਹੈ। ਮੁਫ਼ਤ AI chatbot ਵਿੱਚ ਅਸਲੀ ਨਿੱਜੀ ਡਾਟਾ paste ਕਰਨਾ ਖੁਦ ਉਲੰਘਣਾ ਹੋ ਸਕਦੀ ਹੈ।

**ਅਸਲੀ ਉਤਪਾਦਨ ਡਾਟਾ AI ਨੂੰ ਦੇਣ ਤੋਂ ਪਹਿਲਾਂ ਦੋ ਸ਼ਰਤਾਂ:**

1. **ਸਿਰਫ਼ ਪੇਡ / ਵਪਾਰਕ API tier — Data Processing Agreement (DPA) ਸਮੇਤ:** Anthropic Claude API · OpenAI API / Codex · Google Gemini API (ਸਾਰੇ ਪੇਡ)।
2. **"Training-on-input" ਬੰਦ ਹੈ, ਯਕੀਨੀ ਬਣਾਓ।** ਮੁਫ਼ਤ ChatGPT / Gemini / Claude.ai consumer ਪੱਧਰ ਅਸਲੀ Data Principal ਜਾਣਕਾਰੀ ਲਈ ਅਣਉਚਿਤ।

ਸਿੱਖਣ / ਅਜ਼ਮਾਇਸ਼ / ਕਾਲਪਨਿਕ ਉਦਾਹਰਣਾਂ ਲਈ — ਕੋਈ ਵੀ tier ਠੀਕ ਹੈ। **ਅਸਲੀ ਡਾਟਾ** — ਪੇਡ API + DPA, ਕੋਈ ਅਪਵਾਦ ਨਹੀਂ।
